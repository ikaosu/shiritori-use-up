# 使い切りしりとり(試作)

お題の言葉の文字は最初から消えています。しりとりをつないで、使った文字を二度と使わずに50音を使い切る。

- ① 節約: できるだけ多くの言葉をつなぐ
- ② 最少手数: 少ない語数で使い切る

## 動かす
`index.html` は `data/` を読み込むので、サーバー経由で開く。

    python -m http.server 8000   # → http://localhost:8000/

## 辞書データを作り直す
SudachiDict(Apache 2.0)の CSV を `.cache/` に置いて `python tools/build.py`。
お題の検証は `python tools/curate.py`。

## ルール(確定分)
- 言葉の2文字目以降が消える(頭の文字は前の言葉から引き継ぐ)
- 3文字以上、「を」は対象外(使い切りは45字)
- 濁音・半濁音は清音、小さい字は大きい字として数える。長音は消さず、次は直前の母音から
- 「ん」で終わると続けられない(②では使い切る最後の1語だけ可)
